# Ритм

Трекер привычек на русском языке. Планируйте дела на день, отмечайте прогресс и проходите челленджи вместе с друзьями. Приложение можно установить из браузера на телефон или компьютер.

## Возможности

- **Дневной план и статистика.** Создавайте привычки с расписанием и целями, отмечайте выполнение и следите за сериями.
- **Гостевой режим.** Начните сразу с четырёх редактируемых привычек. Гостевые данные хранятся в браузере.
- **Аккаунт.** Синхронизируйте привычки между устройствами, добавляйте друзей, делитесь привычками и участвуйте в командных челленджах. Новый аккаунт открывается с пустым списком привычек.
- **Напоминания и режим без сети.** Подключите Web Push и пользуйтесь уже загруженным дневным планом при потере связи.

Проект написан на Next.js и TypeScript. Для аккаунтов и синхронизации используются Auth.js, Prisma и PostgreSQL.

## Запуск через Docker Compose

1. Скопируйте `.env.example` в `.env`.
2. Укажите уникальный пароль PostgreSQL в `POSTGRES_PASSWORD` и в `DATABASE_URL`. Для спецсимволов в URL используйте процентное кодирование.
3. Сгенерируйте `AUTH_SECRET` и добавьте его в `.env`.

   ```sh
   node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
   ```

4. Запустите приложение.

   ```sh
   docker compose up --build
   ```

Откройте [Ритм](http://localhost:3000). Compose запускает PostgreSQL, применяет миграции и поднимает веб-приложение и процесс напоминаний. База хранится в томе `postgres_data`.

## Запуск без Docker

Для разработки нужен Node.js 22 и npm. Для аккаунтов также нужен PostgreSQL. В `.env` задайте `DATABASE_URL` со своим адресом базы, `AUTH_SECRET` и `AUTH_URL=http://127.0.0.1:3000`. Выделите для проекта отдельную базу с правами на миграции.

```sh
npm ci
npm run db:migrate
npm run dev
```

Откройте [локальное приложение](http://127.0.0.1:3000). В отдельном терминале можно запустить `npm run reminders`. Для гостевого режима достаточно `npm ci` и `npm run dev`. В Windows PowerShell с запретом скриптов используйте `npm.cmd` вместо `npm`.

## Развёртывание

Укажите публичный HTTPS-адрес в `AUTH_URL` и поднимите перед приложением HTTPS-прокси. Укажите этот же адрес в пользовательских ссылках и разрешите прокси передавать исходный хост. Настройте резервное копирование тома PostgreSQL. Миграции выполняются командой `npm run db:migrate`. Для установки на устройство и Web Push нужны HTTPS либо локальный доверенный адрес.

- **Письма восстановления.** Задайте `SMTP_URL` и разрешённый у почтового провайдера адрес `SMTP_FROM`. Ссылки одноразовые, действуют 30 минут и после сброса закрывают старые сессии.
- **Web Push.** Запустите `npx web-push generate-vapid-keys` и заполните `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY` и `VAPID_SUBJECT`, например `mailto:admin@example.org`. Пользователь выбирает типы уведомлений и включает подписку на устройстве через настройки. При открытом сайте и отключённом push уведомления доступны через кнопку с колокольчиком.
- **Напоминания.** Процесс `reminders` сверяет расписания с локальным временем пользователя. Для ежедневной доставки держите его запущенным. Отправка одного напоминания на привычку и дату защищена уникальным ключом.
- **Работа без сети.** Service Worker сохраняет оболочку приложения. Гостевые данные доступны в браузере. В открытой или восстановленной вкладке аккаунта доступны последние загруженные данные и отметки. Отметки синхронизируются после восстановления связи. Для сохранения очереди до синхронизации держите вкладку открытой.

## Проверки

```sh
npm test
npm run typecheck
npm run build
```

Для интеграционных тестов запустите приложение с отдельной тестовой БД и применённой миграцией. `npm run test:integration` проверяет доступ к данным, заявки, совместные привычки, отметки, опыт, приватность, приглашения в челлендж и выход. По умолчанию тесты используют `http://127.0.0.1:3000`. Переопределить адрес можно через `RITM_TEST_ORIGIN`.

`RITM_TEST_DATABASE_URL` включает проверку напоминаний. Укажите ту же тестовую БД, к которой подключено приложение. `RITM_TEST_SMTP_INBOX` включает проверку восстановления пароля. Укажите путь к файлу `.eml`, в который тестовый SMTP-приёмник сохраняет последнее письмо.

## Структура

- `src/app` содержит маршруты Next.js, API, авторизацию и оболочку PWA.
- `src/components` содержит дневной план, формы, Recharts, настройки и социальные разделы.
- `src/lib/domain.ts` содержит календарные расчёты, подписи типов целей и правила достижений. `src/lib/locale.ts` задаёт язык документа, формат дат и словарь основных разделов. При добавлении языка расширьте словарь и перенесите в него текст экранов.
- `src/lib/validation.ts` определяет общий контракт форм и API. Запись проверяет сессию, ограничения запросов и владельца данных. Ограничения PostgreSQL защищают отметки и начисление опыта от дублей.
- `prisma` содержит реляционную схему и начальную миграцию.
